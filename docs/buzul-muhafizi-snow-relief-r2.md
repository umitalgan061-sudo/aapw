# Buzul Muhafızı R2 — Fold-aware Snow Relief Qualification

R2 qualifies the render-only snow surface fabric already present on current `main`.

The qualification space is 8 slope samples × 8 fold-gradient samples × 8 aspect samples × 8 lee-retention samples = 4,096 production-derived vectors. The generator evaluates the canonical resolver and records the expected deterministic digest and key presentation signals for every vector.

The acceptance gate checks deterministic replay, digest stability, numeric envelopes, windward ridge-crust response, lee-side powder response, sanitization boundaries, and the render-only ownership contract. It does not replace terrain, hydrology, collider, placement, or height authority.
