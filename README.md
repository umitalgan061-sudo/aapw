# AAPW

Web tabanlı bir Progressive Web App (PWA) geliştirme ve test deposudur.

## Genel yapı

Proje; HTML, CSS ve JavaScript tabanlı istemci bileşenleri ile PWA desteği sağlayan manifest ve service worker bileşenlerini içerir.

## Temel özellikler

- Masaüstü ve mobil tarayıcı uyumluluğu
- Progressive Web App desteği
- Offline/cache altyapısı
- Responsive arayüz
- Yerel geliştirme ve test desteği

## Yerel çalıştırma

```bash
python -m http.server 8000
```

veya

```bash
npx http-server
```

Ardından uygulama yerel HTTP sunucusu üzerinden açılabilir.

## Not

Bu depo aktif geliştirme ve doğrulama çalışmaları için kullanılmaktadır.
