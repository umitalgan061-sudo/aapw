# Biome QA entrypoints

The biome asset distribution slice has deterministic acceptance scripts for geography mapping, placement exclusions, surface fabric, single-authority ownership, and the world-coordinate adapter seam.

Run the relevant script with Node 20 from the repository root. The browser/Three.js visual contracts remain the final authority for shipped rendering and real GLB hydration.

This slice intentionally remains additive: it does not replace the existing terrain, vegetation, settlement, natural-geology, player, or Shared Material production owners.
