# 3D model kataloğu

Bu sayfa, depodaki mevcut kişi modelleri ile Ağustos 2026'da eklenen dokulu fantastik
modelleri GitHub üzerinde tek yerde gösterir. Gerçek dosyalar türlerine göre ayrılmıştır;
ejderhalar `creatures`, taht `props`, kişiler `characters` altında tutulur.
